# Robotics Research Portfolio

A standalone, static research portfolio focused on reliable learned and model-based control for legged and wheel-legged robots.

## Local preview

From this directory, serve the site with any static HTTP server, for example:

```powershell
python -m http.server 4173
```

Then open `http://127.0.0.1:4173/`.

No package installation, build step, analytics tracker, external font, or network request is required.

## Pages

- `index.html` — research overview and core projects
- `wheel-legged.html` — wheel-legged RL Sim2Real case study
- `quadruped.html` — EtherCAT quadruped Sim2Real case study
- `systems.html` — real-time systems and field robotics work
- `research.html` — proposed research direction
- `other-research.html` — supporting research

## Privacy and publication scope

Only the static frontend, selected presentation assets, and this public README are versioned and deployed. Local working notes, screenshots, and source materials are excluded. This site intentionally does not include a downloadable CV or personal contact details.

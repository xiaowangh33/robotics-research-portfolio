# Robotics Research Portfolio V2

This is the local V2 working copy of Wang Gufan's static robotics portfolio.
The V1 directory beside it is retained as the backup of the previously
completed site. V2 has not been deployed or pushed to Vercel.

## Local preview

From this directory, run:

```powershell
python -m http.server 4173
```

Then open `http://127.0.0.1:4173/`.

## Pages

- `index.html` — concise overview and research interests
- `wheel-legged.html` — 25 kg wheel-legged control stack and evidence
- `quadruped.html` — 55 kg EtherCAT quadruped control stack and evidence
- `systems.html` — 20-motor migration and field robotics
- `research.html` — proposed research interests and possible method
- `other-research.html` — additional scientific machine-learning work

## Public-facing scope

The site contains selected media, an available CV PDF, and editable inline SVG
figures. Robot source code and internal project records are not exposed;
selected code is available upon request.
